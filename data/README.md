# Data Directory

This directory contains all data files for the project.

##  Structure

```
data/
├── raw/                         # Raw generated time series data
│   ├── unified-test/            # Test dataset (~1.5K samples)
│   ├── unified-5k/              # Small dataset (~5K samples) - Default
│   ├── unified-10k/             # (~10K samples)
│   ├── unified-20k/             # (~20K samples)
│   ├── unified-30k/             # (~30K samples)
│   ├── unified-50k/             # (~50K samples)
│   ├── unified-75k/             # (~75K samples)
│   ├── unified-90k/             # (~90K samples)
│   ├── unified-120k/            # (~120K samples)
│   ├── unified-150k/            # (~150K samples)
│   └── unified-200k/            # Large dataset (~200K samples)
│
└── features/                    # TSFresh extracted features (per-dataset)
    ├── unified-5k/              # Features for 5K dataset - Default
    │   ├── allfeatures/         # All extracted features
    │   │   ├── features.parquet
    │   │   ├── labels.parquet
    │   │   └── feature_names.txt
    │   └── selected/            # Selected features
    │       ├── binary/          # Binary classification features
    │       │   ├── features.parquet
    │       │   └── labels.parquet
    │       └── primary/         # Primary (5-class) features
    │           ├── features.parquet
    │           └── labels.parquet
    ├── unified-20k/             # Features for 20K dataset
    │   ├── allfeatures/
    │   └── selected/
    └── unified-{scale}/         # Features for other scales
        ├── allfeatures/
        └── selected/
```

##  Data Files

### Raw Data (`raw/`)

Generated by scripts in `01-data-generation/`:

- **Format**: Parquet files
- **Columns**:
  - `series_id`: Unique series identifier
  - `time`: Time index
  - `data`: Time series values
  - `is_stationary`: Binary label (True/False)
  - `primary_category`: Main category (deterministic_trends, volatility, stochastic, anomalies, structural_breaks)

### Features Data (`features/unified-{scale}/allfeatures/`)

Extracted by `02-preprocessing/extract_features.py` or `extract_dask.py`:

- **Format**: Parquet files
- **Rows**: Each row = one time series
- **Columns**: 200-800 features (depending on settings)
- **Organization**: Per-dataset subdirectories
- **Examples**:
  - `value__mean`
  - `value__variance`
  - `value__autocorrelation__lag_1`
  - `value__fft_coefficient__coeff_0`

### Selected Features (`features/unified-{scale}/selected/`)

Selected by `02-preprocessing/feature_selection.py`:

- **Purpose**: Reduced feature set for efficient training
- **Organization**: Per-dataset and per-task subdirectories
- **Structure**:
  - `binary/` - Binary classification features
  - `primary/` - 5-class classification features
  - `sub/` - Sub-category features (optional)
- **Method-specific**: Different files for different selection methods

##  Getting Started

### Generate Data

```bash
cd ../01-data-generation

# Test dataset (quick start - 1.5K samples)
python generate.py --scale test

# Default recommended scale (5K samples)
python generate.py --scale 5k

# Full-scale dataset (200K samples)
python generate.py --scale 200k

# See all available scales
python config.py
```

### Extract Features

```bash
cd ../02-preprocessing

# Default: unified-5k dataset
python extract_features.py

# For specific datasets
python extract_features.py \
    --input ../data/raw/unified-test \
    --output ../data/features/unified-test/allfeatures

# Using Dask for faster processing
python extract_dask.py
```

### Extract Features

```bash
cd ../02-preprocessing

python extract_features.py \
    --input ../data/raw/unified-test \
    --output ../data/features \
    --feature-set efficient
```

## 🗑️ Cleanup

To save disk space, you can remove intermediate files:

```bash
# Remove raw data (keep features)
rm -rf raw/

# Remove full features (keep selected)
rm -rf features/features.parquet

# Start fresh
rm -rf raw/ processed/ features/
```
